AbyFlow

SaaS Billing & Subscription API

A production-deployed Flask backend demonstrating secure authentication, Stripe payments, signed webhooks, asynchronous processing and containerized infrastructure.

API Health View GitHub
Capabilities

Backend built like a real SaaS service.

The project focuses on the backend systems required for authentication, billing and asynchronous payment processing.

Authentication

JWT-secured registration, login and protected dashboard endpoints with password hashing and validation.

Stripe Payments

Stripe Checkout integration for payment creation, success handling and cancellation flows.

Webhook Processing

Stripe webhook signatures are verified and events are handled using idempotent database processing.

Asynchronous Jobs

Celery workers process payment tasks through Redis without blocking the main Flask application.

PostgreSQL

Persistent application data and payment state are stored in PostgreSQL.

Docker Infrastructure

Flask, PostgreSQL, Redis and Celery run as isolated services using Docker Compose.

Payment Lifecycle

How a payment moves through AbyFlow

01

Authenticated Client

A JWT-authenticated user requests a checkout session.

02

Stripe Checkout

The user completes payment through Stripe Checkout.

03

Signed Webhook

Stripe sends a signed payment event to AbyFlow.

04

Celery Worker

Redis queues the event and a Celery worker processes it.

05

Database Update

PostgreSQL stores the resulting account state.
